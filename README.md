# Ashiria Goel

Personal site for my robotics and software systems work, with a focus on perception, planning, control, and simulation-to-deployment engineering.

[https://ashiriag.github.io](https://ashiriag.github.io)

## Featured Projects

- **RobotX - Autonomous Surface Vehicle:** ROS2/Python autonomy stack integrating LiDAR, depth cameras, GPS, and Gazebo simulation for maritime navigation.
- **RoboSub - Autonomous Underwater Vehicle:** ROS-based AUV navigation, DVL-IMU sensor fusion, and Unity simulation for underwater mission execution.
- **Temporal Motion Planning for Stealth Navigation:** RRT, A*, and search-based planning over x-y-time state spaces with dynamic visibility and collision constraints.
- **Ping Pong Robotic Arm:** ROS/RViz arm control pipeline using trajectory prediction, inverse kinematics, and motion planning.
